# Reproduce the verified state

Run from the workspace root containing `spectral-krylov-jepa/`. Commands below
use its existing virtual environment. To create another environment, install the
project from `pyproject.toml`; `../astra/2026-09-27/environment-freeze.txt` records
the exact local package snapshot, not a cross-platform tested lockfile.

```sh
mkdir -p .astra/tmp .astra/mpl .astra/cache
export TMPDIR="$PWD/.astra/tmp"
export MPLCONFIGDIR="$PWD/.astra/mpl"
export XDG_CACHE_HOME="$PWD/.astra/cache"
export MPLBACKEND=Agg
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1
spectral-krylov-jepa/.venv/bin/python -m pytest spectral-krylov-jepa/tests tests -q --basetemp="$PWD/.astra/pytest-reproduce"
spectral-krylov-jepa/.venv/bin/python spectral-krylov-jepa/scripts/00_validate_physics.py --out-dir .astra/physics
```

The historical corpus remains locally at
`experiments/raw/smoke_suite_20260926T074651Z`. It is ignored by Git; do not assume a
fresh clone includes HDF5 or checkpoints. The historical smoke runner regenerates
new outputs and may overwrite its old summary, so use an isolated checkout of
starting commit `22e202d` for an exact historical pipeline replay. The audit below
reads the retained corpus directly and writes a new output directory:

```sh
spectral-krylov-jepa/.venv/bin/python spectral-krylov-jepa/scripts/15_verify_data.py --run-dir spectral-krylov-jepa/experiments/raw/smoke_suite_20260926T074651Z --output .astra/historical-data.json
spectral-krylov-jepa/.venv/bin/python spectral-krylov-jepa/scripts/13_audit_baselines.py --run-dir spectral-krylov-jepa/experiments/raw/smoke_suite_20260926T074651Z --output .astra/baseline-replay
```

## Compute-bound full campaigns

Not executed in this task. Run sequentially after reserving a local compute slot
or moving to an appropriate machine. The main design has 192 evaluations; the
supplement has 672. GPU/MPS availability must be checked on the executing host.
Do not launch both at once. Do not use a new run to disguise a failed frozen run.

```sh
spectral-krylov-jepa/.venv/bin/python spectral-krylov-jepa/scripts/11_run_main_experiment.py --config spectral-krylov-jepa/configs/smoke/main_experiment.yaml

spectral-krylov-jepa/.venv/bin/python spectral-krylov-jepa/scripts/12_run_controls.py --scale full --run-dir spectral-krylov-jepa/experiments/raw/astra_controls_full

```

A `RUNNING.lock` in a control directory is fail-closed. Inspect its PID/process
before any recovery; never remove another runner's lock. The main runner uses an
OS advisory lock. Its persistent file is not proof of an active process. Legacy
runs without identities are preserved and cannot be silently resumed.

## Manuscripts and figures

The technical PDF is built with Pandoc and Tectonic:

```sh
pandoc spectral-krylov-jepa/paper/TECHNICAL_REPORT.md -o spectral-krylov-jepa/paper/TECHNICAL_REPORT.pdf --pdf-engine=tectonic -V geometry:margin=1in
```

`paper/build_submission.py` generates the Word draft from the retained official
template and `paper/submission/CJSJ_DRAFT.md`, preserving template styles and page
geometry. Run it with the bundled artifact Python containing python-docx and lxml.
`paper/build_figures.mjs` builds the editable PowerPoint figure using the bundled
artifact runtime; runtime paths are recorded in the builder. The baseline CSV and
figure are regenerated by script 13. The convergence figure comes from script 14.
Ten central manuscript metrics are checked by `scripts/16_build_evidence_registry.py`;
its receipt is `astra/2026-09-27/EVIDENCE_REGISTRY.json`. No arXiv
bundle is designated ready, and no manuscript has been uploaded.
